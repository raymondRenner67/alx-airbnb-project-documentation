# Airbnb Clone - Use Case Diagram

## Overview
This use case diagram illustrates the key interactions between different actors and the Airbnb Clone backend system.

## Actors
- **Guest**: Users who search and book properties
- **Host**: Users who list and manage properties  
- **Admin**: System administrators
- **Payment System**: External payment gateway
- **Email Service**: External notification service

## Key Functionalities
- User registration and authentication
- Property listing management
- Search and filtering
- Booking management
- Payment processing
- Reviews and ratings
- Notifications
